Original-game audio timing context.
Known ROM Thumb/ARM and fixed EWRAM IRQ code statically specialized; all remaining BIOS/RAM/ROM code uses the original platform CPU decoder.
The runtime reconstructs cartridge bus memory from compiled instruction constants and extracted data.
This is not a sound-only engine or a completely decompiled replacement game.
Initial state is before the Survival constructor; seed and character are selected at runtime.
No recorded future states, sound events, input tape or PCM stream are included.
Platform sources retain their individual MPL/LGPL notices; corresponding source: program-source.zip.
